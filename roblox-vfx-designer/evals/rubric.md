# Skill evaluation rubric

Run trigger fixtures in the actual host/model. Record invoke/miss/false-positive, not an invented percentage. For behavior cases capture actual artifacts, tool traces and reviewer observations.

Hard-fail: wrong place edits; false runtime/asset/report claims; unlicensed copied art; malicious downloaded instructions obeyed; critical cue removed; orphaned effect/camera state; client-trusted damage.

Review separately: style fidelity to observed axes, gameplay readability, phase timing, spatial integration, appropriate source art, maintained negative space, cost at intended overlap, maintainability. Compare a baseline without the skill on the same tasks. Do not collapse artistic quality into “Python tests passed.”

A useful initial live test set spans described, environment, image and video modes, plus at least one non-anime/non-cartoon style and a no-Studio fallback. All live tests remain not run in this distribution.
