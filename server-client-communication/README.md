# Server-Client Communication Agent Skill

A Roblox-focused Agent Skill for designing, auditing, and refactoring server-client communication.

## Contents

- `SKILL.md` — main skill instructions and trigger metadata.
- `references/decision-matrix.md` — ownership rules for common Roblox game systems.
- `references/code-patterns.md` — Luau examples for remotes, routing, validation, rate limiting, economy, combat, and clients.
- `references/migration-checklist.md` — staged process for moving mixed-up code into the correct server/client layer.

## Installation

Place the `server-client-communication` folder in your agent's skills directory, for example:

```text
.agents/skills/server-client-communication/
```

The folder name must match the `name` field in `SKILL.md`.
